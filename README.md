# CS330--Comp-Graphic-and-Visualization
3D computational graphics project developed in CS 330 using C++ and OpenGL, demonstrating 3D modeling, transformations, textures, lighting, and interactive visualization.
# CS 330 Module Eight Journal Reflection

## 1. How do I approach designing software?

Working on my 3D scene helped me develop a stronger understanding of how important planning and organization are when designing software. Before this project, I primarily thought about software design in terms of writing code that accomplishes a specific task. Through the development of my 3D scene, I learned to think more about the overall structure of a project, how individual components work together, and how design decisions affect the final result.

One of the most important design skills I developed was translating a visual idea into individual programmable components. I had to determine which objects were needed for my scene, how they should be positioned and scaled, which textures and colors would be appropriate, and how lighting would affect the appearance of the objects. I also learned to think about the scene as a collection of reusable components rather than one large piece of code. Using functions and organized sections for objects, textures, materials, and lighting made the project easier to understand and modify.

My design process involved starting with the overall appearance I wanted for the scene and then breaking it into smaller pieces. I created the basic shapes and positioning first, then added textures, colors, lighting, and other visual details. As I worked through the milestones, I evaluated the results and made adjustments when something did not look or function as expected. This process helped me understand that software design is not necessarily completed in one step. It is an ongoing process of planning, testing, evaluating, and improving.

These design tactics can be applied to future software projects by starting with the larger goal and breaking it into manageable components. Whether I am developing a mobile application, a website, or another type of software, I can use the same approach of planning the structure before implementing individual features. This should make future projects easier to develop, test, troubleshoot, and maintain.

## 2. How do I approach developing programs?

The development of my 3D scene introduced me to several strategies that were different from the programming work I had completed in previous courses. I worked with OpenGL, C++, shaders, meshes, transformations, textures, materials, and lighting. I learned that developing graphics applications requires paying attention not only to whether the code compiles, but also to how the code affects the visual output.

Iteration played a major role throughout the project. I frequently had to make a change, run the program, evaluate the scene, identify a problem, and then make another adjustment. For example, I worked through issues involving textures and lighting and had to examine both my C++ code and the shader-related components when the scene did not appear as expected. I also adjusted object positions, scales, colors, textures, and lighting values to improve the appearance of the scene. This showed me that iteration is an important part of programming rather than simply a response to failure.

My approach to developing code also evolved throughout the milestones. Early in the project, I was more focused on getting individual requirements to work. As the project became more complex, I became more comfortable understanding how different parts of the program interacted. Instead of changing code randomly when something was wrong, I became more deliberate about identifying which component was responsible for the problem and testing changes systematically. I also became more comfortable using debugging information, compiler messages, and the visual output of the application to determine what needed to be changed.

Completing this project taught me that successful development involves persistence and incremental improvement. A program does not have to be perfect on the first attempt. Building a project in smaller stages and continuously testing each change made it possible to eventually combine those pieces into a complete 3D scene.

## 3. How can computer science help me in reaching my goals?

This course gave me new knowledge about computational graphics and visualization that I can apply to my future education and career. Working with 3D graphics helped me understand concepts such as coordinate systems, transformations, textures, lighting, shaders, and rendering. These concepts demonstrated how mathematical and computational principles can be used to create visual experiences that users can interact with and understand.

The project also strengthened my problem-solving skills. When an object did not appear correctly, a texture failed to load, or the lighting did not produce the expected result, I had to investigate the cause and determine how different parts of the program were connected. These troubleshooting skills are valuable beyond computer graphics because software development regularly requires identifying problems, testing possible solutions, and refining an implementation.

The skills I gained from this project can also support my future educational pathway in computer science and software engineering. Understanding how software interacts with visual elements gives me another perspective on application development and user experience. It also gives me experience working with a programming environment and development process that is different from traditional application programming.

Professionally, computational graphics and visualization can be useful in areas such as game development, simulations, interactive applications, visualization tools, user interfaces, and other software that communicates information visually. Even if my future career is not specifically focused on graphics programming, the skills I developed in this course—problem solving, debugging, iteration, organization, attention to detail, and translating requirements into working software—are directly applicable to software engineering.

Overall, this project helped me see how the concepts I learn in computer science can be combined to create a complete working product. The 3D scene is not only an example of what I learned about graphics programming, but also evidence of my ability to take requirements, develop a solution, troubleshoot problems, and continue improving the result until the project is complete.
